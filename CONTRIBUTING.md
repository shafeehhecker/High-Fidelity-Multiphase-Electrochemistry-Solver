# Contributing to HFMES

Thanks for your interest in this project! Here's how things work around here.(sorry about it)

## 🍴 Forking

This is primarily a solo academic research project, but the code is open for anyone to learn from, build on, or repurpose.

- **Fork it freely.** Take the solver, the LBM/FEM code, whatever's useful — no need to ask permission first.
- **Do whatever you want with your fork.** Rip out modules, change the physics models, retarget it for a different problem, use it as a teaching example — it's yours to experiment with once forked.
- If you build something interesting on top of it, a mention or link back is appreciated but not required.

## 🔧 Working on the Code

Since this project evolves alongside ongoing research (see the roadmap in the README), the codebase and priorities may shift as stages progress. If you're picking this up:

1. Check the README's roadmap to see which stage is currently active.
2. Look at the checked/unchecked task list to understand what's done vs. in progress.
3. Feel free to work on any open item, or bring your own ideas.

## 📬 Pull Requests & Getting in Touch

This repo doesn't use the standard GitHub PR review flow for now. If you'd like to:

- Submit a pull request
- Propose a significant change
- Discuss the mathematical formulations or coupling strategies
- Report a bug or suggest an improvement

Please reach out directly through **[www.shafeeh.com](https://www.shafeeh.com)** rather than opening a PR blind. This helps make sure contributions align with the current research direction before time is spent on them.

## 🐛 Issues

Feel free to open GitHub issues for bugs, questions, or discussion — these are welcome and monitored.
